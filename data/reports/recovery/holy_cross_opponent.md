# Holy Cross official opponent recovery

Accepted 3 verified official boxes, adding 3 detailed-stat games
to the dependency stack. The snapshot has 805 detailed-stat games and 1,355
unique games. Previously collected older rows and split ranges stay intact.

Box-score requests target matching existing Ivy-versus-holy-cross games. Each accepted box
has a matching date/team pair, final scores, team statistics and consistent quarter
totals. The manifest's school is the actual participating Ivy team; URLs retain
the opponent's official host. Source copies are merged rather than duplicated.

Fetcher handles robots, configured identity, delays and verified cache reuse.
The request inventory records successful discovery, accepted boxes, failures and
unfetched requests separately. There are 19 persisted source diagnostics.
The linked common footer terms were inspected; no raw pages or printed header records
are published as model features.

Validation: 373 offline tests, 0 errors, 281 warnings in the integrated
snapshot. Every accepted URL joins exactly one existing full-stat game. Missing
statistics stay missing. Issue #9 remains open for additional coverage.

Two games use parsed 2016 HTML reports. The third is an explicitly reviewed
factual excerpt from page 20, right column of the 2015 spring prospectus:
Harvard–Holy Cross on September 19, 2014, 41–18. The source recap names Harvard
Stadium; the official 2014 schedule corroborates the home designation. Quarter
scores and team-stat columns were visually checked. The excerpt retains the
original game date, complete-source hash/fetch time and page/region pointer.

This is manual review of one game's explicit values, not automatic PDF parsing.
Unknown rushing attempts, punt yards and other absent lines remain missing.
Rounded punt averages are not multiplied into purported exact yard totals, and
player statistics are not summed. The build verifies unchanged successful PDF
evidence and rejects unknown record fields, invalid identities/statistics or
stale proof before replacing output files. Standard merging, pre-game records,
turnovers and splits apply to the excerpt. No new runtime dependency or output
column is introduced.
